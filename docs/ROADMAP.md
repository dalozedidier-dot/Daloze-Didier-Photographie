# Feuille de route

## Phase 1 — Portfolio

- intégrer les photographies originales sélectionnées
- construire 4 à 8 séries cohérentes
- ajouter titres, années et textes courts
- optimiser les images pour le web
- vérifier l’affichage mobile
- activer GitHub Pages
- connecter éventuellement un nom de domaine

## Phase 2 — Protection et référencement

- métadonnées Open Graph
- sitemap
- favicon et identité visuelle
- page mentions légales
- page politique de confidentialité
- marquage discret ou stratégie anti-réutilisation si souhaitée
- versions web sans fichiers haute définition
- données structurées pour le référencement

## Phase 3 — Vente

### Option simple

Chaque photo vendable reçoit un lien de paiement hébergé.

Avantages :
- pas de backend à maintenir
- pas de carte bancaire stockée sur le site
- compatible avec un site statique
- mise en place progressive

### Option boutique complète

Ajouter :
- variantes de format
- choix du papier
- stock ou séries limitées
- panier
- frais de livraison
- confirmation de commande
- gestion des licences

À ce stade, on pourra conserver GitHub comme dépôt de code et déployer la partie dynamique chez un hébergeur adapté.

## Modèle de données déjà prévu

Chaque photo peut contenir :

- titre
- catégorie
- texte alternatif
- année
- état de vente
- prix de départ
- URL de checkout

Cela permet d’activer la vente photo par photo sans refaire la galerie.
