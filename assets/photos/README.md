# Photos du portfolio

Place ici uniquement les versions destinées au web.

Recommandations :

- WebP ou AVIF
- côté long : environ 1800 à 2400 px
- conserver les originaux haute définition hors du dépôt public
- nom de fichier simple, sans espaces
- exemple : `lion-regard-01.webp`

Les photos sont ensuite déclarées dans `assets/data/photos.js`.
